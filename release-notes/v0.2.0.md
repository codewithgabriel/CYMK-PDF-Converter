## Download and update

Download **Inkwell_0.2.0_x64-setup.exe** below. Close Inkwell, run the installer, and follow the setup prompts to update your existing installation. This is the full installer for Windows 10/11 x64; new users can install it directly too. Rust, Node.js, and a separate Ghostscript installation are not required. The offline WebView2 runtime is included.

## New in 0.2.0

- A redesigned document workspace with Image Studio and the existing CMYK PDF ink optimizer.
- Open a Word `.docx` document with page previews, an image list, and comment controls beside detected pictures.
- Generate realistic, refined, or illustrated replacements from a selected image. Instructions are optional; nearby document text can provide context, with an option to exclude it.
- Choose image quality and resolution, compare drafts with the original, and accept only the images you want.
- Export a new DOCX containing accepted replacements while retaining the original document's text, tables, styles, and other image placements.

For image generation, open **AI settings** and enter your own OpenAI API key. Generation requires internet access and is billed to that API project. The key stays in memory for the current app session. No shared developer key is included. Opening documents and optimizing PDFs work locally without an API key.

Close the app only after exporting accepted images; drafts are held for the current document session. Review AI images before accepting them. The document preview approximates Word pagination; export retains the original layout XML.

The installer is currently unsigned, so Windows may display an unknown-publisher warning. SHA256SUMS.txt contains download checksums. Ghostscript-UPSTREAM.json identifies the bundled Ghostscript release and its verified upstream checksum. Inkwell and its bundled Ghostscript runtime are distributed under AGPL-3.0-or-later; corresponding Inkwell source is available under this release's source downloads, and Ghostscript source is available at the recorded upstream Artifex release.
