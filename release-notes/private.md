Download the setup `.exe` below, close Inkwell, and run the installer to update. New installations use the same file. Windows 10/11 x64 is supported.

This private edition includes the shared OpenAI API key: open a DOCX, select an image, and generate. No account or API key setup is needed in the app. Internet access is needed for image generation; usage is charged to the configured OpenAI project.

New in 0.2.0: Image Studio, optional instructions and document context, high-resolution image generation, comparison and review, and DOCX export with accepted image replacements. The CMYK PDF optimizer is also included.

Keep this installer and the installed app between the intended two users. The compiled key can be extracted; private repository access and HTTPS protect distribution, not the key from someone who receives the executable. Do not upload this build to public releases or file-sharing links. If it is shared beyond the intended recipients, revoke the key and rebuild with a replacement.

The installer includes Ghostscript and the offline WebView2 runtime. It is unsigned. SHA256SUMS.txt records its checksum; UPSTREAM.json records the exact bundled Ghostscript release. Source code and AGPL license notices are included in this repository and the upstream Artifex release.
